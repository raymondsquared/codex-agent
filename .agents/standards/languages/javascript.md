# JavaScript Coding Standards

- Prefer TypeScript when possible.
- Use ESLint as the primary style guide and enforcement tool.
- Write code for modern JavaScript runtimes.
- Favour readability and maintainability over clever code.
- Use explicit comparisons for strings and numbers.
- Declare variables close to where they are used.
- Use default parameters instead of mutating inputs.
- Put default parameters last.
- Use implicit return in arrow functions only when it improves clarity.
- Use `class` and `extends` for class based inheritance.
- Use computed property names for dynamic keys.
- Use object rest to omit properties when creating derived objects.
- Use `Array#push` for adding items.
- Use spread syntax to copy arrays.
- Use `Array.from` for array like values.
- Use `Number()` for numeric conversion.
- Avoid splitting long strings with `+` concatenation.
